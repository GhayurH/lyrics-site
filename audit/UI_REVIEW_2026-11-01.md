## Maintainability assessment

**Preserve:** Astro static rendering with progressive enhancement; canonical parsing in `src/lib/`; shared `ReadingControls.astro`, edition state, theme/font allowlists, design tokens, and source IDs. R2-backed scans have useful native-link fallbacks. Long-lived recitation programme formats and organizer authorization must remain stable.

**Candidate future extractions:** `reading-columns.css` (~590 lines) interleaves edition grids, toolbar/navigation UI, scans, and index styles; `basta.css` (~670 lines) covers multiple concerns; `recitation-builder.ts` and `recitation-reader.ts` are substantial controllers. Split by responsibility only with import-order and functional regression tests. Repeated selectors inside container/media queries are usually intentional, and `!important` may protect native hidden states or image-only fallbacks; do not blindly delete them. Comments explaining non-obvious behavior are useful, whereas historical patch notes should be replaced with present-tense invariants.

**Documentation:** README is already a short entry point; Architecture, Contributing, Assets, and Recitation Sets each own distinct rules. Keep technical audits here instead of adding internal details to the public About page or bloating README.

**Limitations:** This is an initial source audit and implemented fixes, not a complete hands-on cross-device audit. Automated browser tests do not replace screenshots, browser zoom tests, and accessibility review.

## Subsequent consolidation

- The floating-scan controller now detects an actual adjacent visible text panel rather than ruling out portrait screens independently of the reader's container layout.
- Removed an unused `lyric-reading-grid-single` class. The shared `data-reading-mode` rules already size single-language editions.
- Added Chromium coverage for scan geometry in portrait, landscape, and desktop, alongside a design ownership test.

- Basta page progress previously read only `window.scrollY`, even though Focus Mode scrolls in a fixed reader. Progress now uses the active scroller, with a browser regression.
- Reworded historical implementation comments in Focus Mode and Recitation CSS as current behavior contracts.

- Retracted site headers used `visibility:hidden`, removing navigation controls from keyboard tab order. They now translate offscreen without losing keyboard reachability; focusing a header control reveals it. Tests assert actual geometry rather than CSS visibility.

- Completed the paired Focus resume behavior: both saving and restoring page-by-page Basta offsets now use the active scroller. Direct `?reading=1&resume=…` links no longer restore the hidden document.
- Focus Options previously treated Escape as a request to exit the entire reader. Escape now dismisses an open Options panel and returns focus to its toggle; the next Escape exits.
