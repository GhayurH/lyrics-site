# Codex instructions for added Round 2 kalams

This is one bounded editorial review, not an autonomous import, translation, deduplication, background service or tracking operation.

- Read AGENTS.md and docs/EDITORIAL.md first. The latter is the canonical reference, overriding the historic imported-worker prompt.
- Source-language verse text belongs in the Markdown body, Roman transliteration in a YAML romanLyrics literal block. Non-English kalams must NEVER contain English translations. English originals remain English.
- Determine original language from source evidence: Urdu ur, Panjabi Shahmukhi pa-Arab, Saraiki skr-Arab, Balti bft-Arab, Arabic ar, Persian fa. Do not infer language from keyword matches or turn a genuine Latin-script original into a false Arabic-script original.
- For Roman-only poems, reconstruct source-language text only when wording can be verified. Roman writing is ambiguous evidence; do not invent words, diacritics, stanza alignment or historical versions. If needed, leave the item blocked and describe evidence needed.
- Roman spelling: ASCII except ṅ/Ṅ for nasal ں; n for ن; aa/u/i long vowels; final Urdu ے generally e; Husain, Hasan, Bibi, Kiun/Kiuṅ, Ae for vocative اے, Gham-e-Husain for izafat, Shab o Roz for conjunction و, bewafa and baar baar. Preserve Zehra or Zahra according to the poem.
- Urdu source stanza numbers are ۱ ۲ ۳; Roman numbers are 1 2 3. Leave no empty line after a stanza numeral. Keep preambles distinct, strip standalone Saani and Antra labels while retaining real opening and stanza boundaries.
- A source-language honorific stays where verified; do not add honorifics to Roman. Remove recitation x2 markers only, replacing in-verse markers with a comma. Preserve words, takhallus, repetitions with editorial significance, punctuation and original verse order.
- Never force alignment merely to equalize line counts. Respect printed sources and avoid OCR guesses. Keep meaningful variants and identify unresolved source/audio decisions.
- Change only the selected lyric; never alter unrelated poems, Basta, source archives, provenance or historical trackers, identity locks, URLs or docs. Never commit, push, deploy or execute broad normalization as part of this single-file task.

Conclude with the file reviewed, actual edits made, and unresolved questions requiring human verification.
