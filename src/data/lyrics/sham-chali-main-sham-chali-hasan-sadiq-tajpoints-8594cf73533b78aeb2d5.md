Sham Chali Main Sham Chali Hasan Sadiq.
Pardais Mein Ghar Lutwa Ke Par Tera Deen Bacha Ke Main Sham Chali Nana.

1
Be Goor-o-Kafan Bhai Hai Mera Asbab Luta Hai Ghar Bhi Jala.
So Teer Ghamo Ka Kha Ke Aankhon Se Khon Baha Ke Main Sham Chali Nana.
Bhai Ka Gala Kattay Dekha Qasim Ka Badan Pamal Howa.
Akbar Ka Dard Utha Ke Hathoon Mein Rasan Bandhwa Ke Main Sham Chali Nana.

2
Ghazi Ke Baad Main Ghazi Hoon Main Nad-e-Ali Dohrati Hoon.
Khutbon Ki Taig Chala Ke Ghazi Ka Alam Lehra Ke Main Sham Chali Nana.
Rasi Mein Sakina Ka Hai Gala Sajjad Pehan Kar Tauq Chala.
Lo Shimar Ke Durray Kha Ke Main Sabar-e-Hussain Dikha Ke Main Sham Chali Nana.

3
Do Lal Fida Bhai Pe Kiye Main Roi Nahi Dono Ke Liye.
Aankhon Mein Ashk Chupa Ke Bhai Ka Dard Bana Ke Main Sham Chali Nana.
 Rehan Nabi Zadi Ne Kaha Aye Karb-o-Bala Aye Karb-o-Bala.
Nana Se Kahon Gi Ja Ke Main Aa Gayi Deen Bacha Ke Main Sham Chali Nana.
