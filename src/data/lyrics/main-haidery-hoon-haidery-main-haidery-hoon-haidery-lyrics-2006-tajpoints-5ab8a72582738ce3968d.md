Main Haidery Hoon Haidery Main Haidery Hoon Haidery.
Jibreel Ke Ustad Ki Karta Hoon Main Bhi Nokari.
Rag Rag Mein Hai Boye-e-Abbas Ka Sadqa Mila.
Maskh-o-Alam Se Pyar Hai Janat Meri Farsh-e-Azza.
Saya Alam Ka Sar Pe Hai Khata Hoon Unn Ki Hazari.
Meesum Ka Wirse Dar Hoon Main Sahib-e-Dastar Hoon.
Hur Hai Mere Ahbab Mein Main Kausari May Khuwar Hoon.
Meri Azaan Madh-e-Ali Ishq-e-Ali Hai Bandagi.
Kyun Na Karon Madh-e-Hasan Unn Ki Sana Husan-e-Sukhan.
Jab Zehan Mein Aate Hain Woh Khushbo Mein Dhalta Hai Badan.
Mere Qalam Ko Unn Se Hi Shamsheer Ki Qowat Mili.
Khak-e-Dar-e-Shabir Par Sajde Mein Rakha Hai Yeh Sar.
Aisa Laga Hai Pusht Par Meri Khare Khair-ul-Bashar.
Main Wajd Mein Parhne Laga Naat-e-Nabi Nad-e-Ali.
Hoon Khadam-e-Farsh-e-Azza Aye Shair-e-Madar Marhaba.
Sharyan Mein Khoon Ban Ke Hai Noha Salam-o-Marsiya.
Iss Se Bara Kya Ho Sharaf Bachpan Se Main Hoon Matami.
Jad Hain Abu-Talib Mere Jo Deen Ki Bunyad Thay.
Islam Jin Ke Ghar Pala Eman Jin Ke Dam Se Hai.
Le Kar Ali Ko Gaud Mein Kehte Rahe Woh Bhi Yehi.
Woh Jo Wajhiullah Hain Har Baat Se Aagah Hain.
 Rehan Sari Mushkilein Jaise Ke Sang-e-Rah Hain.
Tofaan Larz Jate Hain Jab Parhta Hoon Main Nad-e-Ali.
