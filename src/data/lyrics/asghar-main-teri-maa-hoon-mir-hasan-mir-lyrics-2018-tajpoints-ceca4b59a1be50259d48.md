1
Asghar Main Teri Maa Hoon Mir Hasan Mir
Aa Jao Chand Mere Teri Pyas Main Bhujaon Asghar Main Teri Maa Hoon.
Mere Ladlay Kahan Ho Seene Tumhein Lagaon Asghar Main Teri Maa Hoon.
Beta Tumhara Qatil Mere Samne Khara Hai Jane Kyun Hans Raha Hai.
Chadar Bhi Lut Chuki Hai Munh Kis Tarha Chupaon Asghar Main Teri Maa Hoon.
Tere Jhole Ko Sakina Ro Ro Ke Chomti Hai Tujhe Ghar Mein Dhondti Hai.
Teri Maut Ki Khabar Main Kaise Osse Sunaon Asghar Main Teri Maa Hoon.
Meri Jan Ja Rahi Hai Yeh Soch Soch Asghar Iss Phol Se Galay Par.
Yeh Teer Kaise Jhaila Behno Ko Kya Bataon Asghar Main Teri Maa Hoon.
Naizay Se Gir Raha Hai Nana Sa Sar Tumhara Dil Rota Hai Hamara.
Mere Hath Tu Bandhe Hain Sar Kis Tarha Uthaon Asghar Main Teri Maa Hoon.
Jhole Ke Sath Beta Mere Hath Jal Gaye Hain Zalim Bhi Hans Rahe Hain.
Teri Aakhri Nishani Haye Kis Tarha Se Bachaon Asghar Main Teri Maa Hoon.
Jab Raat Ho Gi Run Mein Ho Jaye Ga Andhera Darna Nahi Aye Beta.
Dadi Kahin Gi Tum Se Aa Main Tujhe Sulaon Asghar Main Teri Maa Hoon.
Tum Raat Ko Hamesha Sunte The Maa Se Lori Ab Neend Aati Ho Gi.
Phir Gaud Mein Lita Kar Nad-e-Ali Sunaon Asghar Main Teri Maa Hoon.
