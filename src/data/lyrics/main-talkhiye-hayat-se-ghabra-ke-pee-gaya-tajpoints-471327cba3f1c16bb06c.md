Main Talkhiye Hayat Se Ghabra Ke Pee Gaya.
Gham Ki Siyah Raat Se Ghabra Ke Pee Gaya.

1
Itni Daqeeq Shey Ko Koi Kaisey Samaj Sake.
Yazdaan Ke Waqiyat Se Ghabra Ke Pee Gaya.
Chalke Howay The Jaam Pareshaan Thi Zulf-e-Yaar.
Kuch Ayse Hadsaat Se Ghabra Ke Pee Gaya.

2
Main Admi Hoon Koi Farishta Nahi Hazoor.
Main Aaj Apni Zaat Se Ghabra Ke Pee Gaya.
Duniya-e-Hadsaat Hai Aik Dard Naak Geet.
Duniya-e-Hadsaat Se Ghabra Ke Pee Gaya.

3
Kante Tu Khair Kante Hain Inn Se Gila Hi Kiya.
Pholon Ki Wardaat Se Ghabra Ke Pee Gaya.
 Sagar Woh Keh Rahe The Ke Pee Lijiye Hazoor.
Unn Ki Guzarshaat Se Ghabra Ke Pee Gaya.
