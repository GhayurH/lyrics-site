1
Main Faqeer Hoon Main Malang Hoon.
Main Faqeer Hoon Main Malang Hoon Main Ali Wali Ka Ghulam Hoon.
Mujhe Fakhar Hai Keh Ghulam Main Mere Maula Ka Sar-e- Aam Hoon.
Wohi Aasra Hai Gareebon Ka Wohi Aasra Hai Faqeeron Ka.
Wohi Maula Mera Ali Wali Karon Aam Jis Ka Pyam Hoon.
Meri Fikar Kiya Meri Baat Kiya Bas Ali Ali Hai Meri Sada.
Hai Jo Marifat Se Bhari Hoi Wohi Baat Main Woh Kalam Hoon.
Ya Ali Kaha Tu Dareecha Ilm Ka Wa Howa Mere Wajad Mein.
Main Ne Pocha Keh Yahan Kaun Hai Tu Atta Yeh Boli Ilham Hai.
Jo Na Havi Mujh Pe Ali Na Ho Tu Main Kiya Hoon Mujh Ko Khabar Hai Yeh.
Mein Hoon Sang -o- Khak Haqeer Tar Be Khiyal Fikar Main Kham Hoon.
