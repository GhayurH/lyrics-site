سونا جنگل گھور اندھیرا اصغر آجا پاس

بانو نے کہا جان سے پیارے علی اصغر
کیا سو گئے دریا کے کنارے علی اصغر

تم پاس تھے میرے تو لگا رہتا تھا جی بھی
تنہائی میں ماں کس کو پکارے علی اصغر
پیارے علی اصغر

۱
تم جس کی امانت تھے گئے پاس اسی کے
کیوں چھٹتے اگر ہوتے ہمارے علی اصغر
پیارے علی اصغر

۲
وہ دھوپ کی شدت سے دن کٹ گیا لیکن
کس طرح سے ماں رات گزارے علی اصغر
پیارے علی اصغر

۳
آجاؤ تو جی بھر کے تمہیں پانی پلا لاؤں
یاں کیوں ہے چچا نہر کنارے علی اصغر
پیارے علی اصغر

۴
اکبر ہیں نہ قاسم ہے نہ اب عون و محمد
سب ٹوٹ چکے میرے سہارے علی اصغر
پیارے علی اصغر

۵
دن ڈھل گیا رات آ گئی ڈر لگتا ہے بیٹا
پھر کوئی شقی تیر نہ مارے علی اصغر
پیارے علی اصغر

۶
اک لمحے کو پھر خیمے میں آجاؤ کہ مادر
وہ خوں بھرا کرتہ تو اتارے علی اصغر
پیارے علی اصغر

۷
آغوش میں تم ہو گے تو شاید یہ ستمگار
باندھیں گے نہ پھر ہاتھ ہمارے علی اصغر
پیارے علی اصغر

۸
کہرام تھا عزت لبِ بانو پہ بکا تھی
آجاؤ کہ ماں جان کو وارے علی اصغر
پیارے علی اصغر
