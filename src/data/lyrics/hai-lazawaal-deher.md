ہے لازوال دہر میں تیری وفا غازی

۱
فنا نہیں جسے مر کے ہے وہ بقا غازی
تیری وفا غازی بقا غازی
فقط محیط نہیں کربلا پہ اس کی وفا
قدم قدم پہ ہوا مولا پر فدا غازی
تیری وفا غازی بقا غازی

۲
لب فرات سے زہرا کی آ رہی تھی صدا
تو میری بیٹی کا واحد تھا آسرا غازی
تیری وفا غازی بقا غازی

۳
قیام آل عبا میں ہوا ہے حشر بپا
علی کے لال سے جس دم ہوا جدا غازی
تیری وفا غازی بقا غازی

۴
رہی ہے دیر تلک بازو چومتی زینب
ام البنین کو جس دم ہوا عطا غازی
تیری وفا غازی بقا غازی

۵
امیر اس کا بدل کوئی نہیں زمانے میں
جہاں میں ملک وفا کا ہے کبریا غازی
تیری وفا غازی بقا غازی
