Sajday main, sar kata kay, Shabbir Karbala main

Badli hai La Illah ki, taqdeer Karbala main

Asghar teray jihad ki, kiya dehe,r day misaal

Aye nazar lahu ki, taseer Karbala main

Touheed bach na paati, hota, na aaj parda

Laatay ager Hussain na, hamsheer Karbala main

Samjhi behen kay lout kay, Akbar, hai agaya

Gonjhi subhay Aashor jo, takbeer Karbala main

Thamay jigar ko apnay, Shabbi,r chun rahay hain

Bikhri howe Hasan ki, tasveer Karbala main

Deekha jo khawab Ahmed e, Mursal, ki ankh nay

Aus ko aata howe hai, tabeer Karbala main

Aik Maa kay dil main Shahid, paiwa,st aaj tak hai

Nikla tha jo kaman say, aik teer Karbala main
