1
Pareshan Raat Sari Hai Sitaron Tum To So Jao.
Sakoot-e-Marg Tari Hai Sitaron Tum To So Jao.
Hanso Our Hanste Hanste Dobte Jao Khalaon Mein.
Humein Par Raat Bahri Hai Sitaron Tum To So Jao.

2
Huemin Tu Aaj Ki Shab Pho Phate Tak Jagna Ho Ga.
Yehi Qismat Humari Hai Sitaron Tum To So Jao.
Tumhein Kya Aaj Bhi Koi Agar Milne Nahi Aaya.
Yeh Bazi Hum Ne Hari Hai Sitaron Tum To So Jao.

3
Kahe Jate Ho Ro Ro Kar Humara Haal Dunya Se.
Yeh Kaisi Raazdari Hai Sitaron Tum To So Jao.
Humein Bhi Neend Aa Jaye Gi Hum Bhi So Hi Jaein Gay.
Abhi Kuch Beqrari Hai Sitaron Tum To So Jao.
