وقت سجاد نے کیسے وہ
وقت سجاد نے کیسے ( میرا بیمار امام ) ز2
( وقت ساجاد نے کیسے وہ گزارا ھوگا ) ز4
( وقت سجاد نے کیسے وہ گزارا ہو گا ) ز2
نام زینب کا جو غیروں نے پکارا ہو گا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
یا رب کوئی مل جائے نا پہچااننیوالا
( بازار میں سجاد دعا مانگ رہا ہے ) ز2
لو حسین ابن علی پیاسے ذبح ہونے لگے ز2
کتنا شرمندہ وہ دریا کا کنارہ ھوگا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
وہ گرا زین سے زینب کی ردا کا ضامن ز2
کون اب فاطمہ جائی کا سہارا ھوگا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
سر میدان تو جانے تو لگا ہے اصغر ز2
کس طرح تیرے بنا ماں کا گزارا ھوگا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
نوک نیزا پہ بہانے لگے آنسو مولا ز2
پھر سكینہ کو کسی شخص نے مارا ھوگا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
روز محشر کا ہمیں ڈر نہیں کوئی شوکت ز2
ہاتھ شبیر كے قدموں پہ ہمارا ھوگا
( وقت ساجاد نے کیسے وہ گزارا ھوگا )
