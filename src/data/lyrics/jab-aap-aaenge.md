گلے ملو سب درود پڑھ کر حسد کی دیوار توڑ والو۔
دلوں میں بغض و حسد رہا تو حسین کا غم کہاں رہے گا۔
لبوں پہ غیبت دلوں میں نفرت فریبی آنکھیں مکان غاصبی۔
بلا رہے ہو جسے بتاؤ وہ آ گیا تو کہاں رہے گا؟

۱
اٹھا کے غیب کا پردہ جب آپ آئیں گے۔
دکھائی دے گا سویرا جب آپ آئیں گے۔

۲
سکھایا کس نے تھا گودی میں بولنا ان کو۔
یہ خود بتائیں گے عیسیٰ جب آپ آئیں گے۔

۳
سکون سے بیٹھا ہو پہلو میں شیر کے آہو۔
یہ دیکھنے کو ملے گا جب آپ آئیں گے۔

۴
ابھی تو نکلا ہے سورج مگر اندھیرا ہے۔
نصیب ہوگا اجالا جب آپ آئیں گے۔

۵
نکالے جائیں گے اہلِ نفاق قبروں سے۔
نبی کو چین ملے گا جب آپ آئیں گے۔

۶
کھجوریں چاکِ شکم سے نکالی جائیں گی۔
حساب ہوگا فدک کا جب آپ آئیں گے۔

۷
کبھی علی کی زبان سے جو لوگ سنتے تھے۔
سنائی دے گا وہ خطبہ جب آپ آئیں گے۔

۸
ابھی تو دھوپ میں فتووں کی ہیں ابو طالب۔
شجر بھی اوڑھے گا سایہ جب آپ آئیں گے۔
